# NEUROPIX AI — структура проекта

```text
/
├── index.html
├── assets/
│   ├── styles.css
│   ├── script.js
│   ├── prices.js
│   ├── images.js
│   └── README.md
└── photo/
```

## Изображения
Все изображения кладутся непосредственно в `photo/`.

Формат имени: `[service]-[двухзначный номер].jpg`.

Для каждой пары «до/после»:
- нечётный файл — ДО;
- следующий чётный — ПОСЛЕ.

Пример реставрации:
- `photo/restoration-01.jpg` — до;
- `photo/restoration-02.jpg` — после;
- `photo/restoration-03.jpg` — до;
- `photo/restoration-04.jpg` — после;
- `photo/restoration-05.jpg` — до;
- `photo/restoration-06.jpg` — после.

Список всех путей редактируется только в `assets/images.js`.

## Цены
Все цены, коэффициенты сложности, срочности и пакетные скидки находятся только в `assets/prices.js`.

## Калькулятор
Калькулятор открывается поверх страницы. Его можно:
- переносить за верхнюю панель;
- сворачивать;
- разворачивать;
- закрывать;
- добавлять несколько услуг;
- удалять отдельные услуги.

Ширина окна — 650 px, максимальная высота — 90% высоты экрана. При переполнении появляется вертикальная прокрутка.

## GitHub Pages
Загрузите всю структуру в репозиторий, затем включите `Settings → Pages → Deploy from a branch → main → /root`.

Перед публикацией замените контактные данные в `index.html`. Форма на статическом GitHub Pages открывает почтовую программу через `mailto:`.

## Макет и темы
Максимальная ширина контента — 1900 px. На широком экране описание услуги и три примера «до/после» выводятся крупными карточками; на меньшей ширине галерея перестраивается в 2 или 1 колонку без уменьшения карточек до нечитаемого размера.

Светлая тема построена на серо-светлой палитре без чисто белых больших секций. Тёмная тема остаётся тёмной во всех крупных секциях, включая FAQ, CTA, футер и калькулятор.
